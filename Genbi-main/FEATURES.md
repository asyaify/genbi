# Genbi — Описание функционала и журнал изменений

## Что такое Genbi

**Genbi** — AI-powered BI-чат для анализа OLAP-куба (SSAS Tabular). Пользователь задаёт вопросы на естественном языке, система автоматически генерирует DAX-запросы, выполняет их и визуализирует результат.

---

## Архитектура

```
Пользователь (Streamlit UI)
       │
       ▼
Декомпозитор (LLM) ─── разбивает запрос на метрики/измерения/фильтры
       │
       ▼
RAG Engine (Qdrant) ─── находит меры и столбцы по embeddings
       │
       ▼
DAX Generator (LLM) ─── генерирует DAX на основе контекста
       │
       ▼
SSAS Executor (XMLA) ── выполняет DAX, возвращает DataFrame
       │
       ▼
Retry Loop ─────────── при ошибке SSAS → самокоррекция LLM (до 2 попыток)
       │
       ▼
Визуализация + Экспорт
```

**Модели:**
- LLM: `gemini-3.1-flash-lite-preview` (aitunnel.ru)
- Embeddings: `text-embedding-3-small`

## Реализованный функционал

### Ядро (Backend)

- **Декомпозиция запросов** — LLM-агент извлекает из естественного языка: метрики, измерения, фильтры, временной контекст
- **RAG-поиск** — семантический поиск мер и столбцов в Qdrant по embeddings декомпозиции
- **Генерация DAX** — LLM генерирует EVALUATE/SUMMARIZECOLUMNS запросы с фильтрами, ORDER BY, TOPN
- **Авто-корректор опечаток** — fuzzy-matching имён мер (`difflib.get_close_matches`)
- **Retry с самокоррекцией** — при ошибке SSAS ответ с ошибкой отправляется обратно в LLM для исправления (до 2 retry)
- **Авто-определение диапазона данных** — `_detect_data_years()` запрашивает куб при старте, определяет годы (2019–2022); промпт автоматически подставляет актуальный `{latest_year}`
- **Аутентификация SSAS** — поддержка Basic Auth, NTLM и auto-режим

### Визуализация (Frontend)

- **6 типов графиков** — гистограмма (горизонтальная), линейный, круговая, treemap, точечная диаграмма, область
- **Интерактивная панель** (стиль Grafana):
  - Выбор типа графика (selectbox)
  - Выбор осей X / Y (selectbox + multiselect)
  - Справочные линии: среднее, медиана (checkbox)
- **Smart-агрегация** — при >15 категорий → топ-15 + «Остальные (N)»
- **Условное форматирование таблиц** — цветовой градиент по числовым столбцам (`background_gradient`)
- **Drill-down предложения** — кнопки «Детализация по лидеру», «Динамика по месяцам», «Разбивка по другому измерению»

### KPI-карточки

- **Умная логика метрик:**
  - Абсолютные (выручка, количество) → Итого + Макс
  - Относительные (средний чек, %, наценка) → Медиана + Диапазон
- Количество записей и уникальных категорий
- Определение типа метрики по ключевым словам (`средн`, `доля`, `процент`, `%`, `наценка`, `рентаб`, `коэффициент`)

### Executive Summary

- Обзор данных (строки, колонки)
- Качество данных (пропуски)
- Ключевые метрики с агрегатами
- Выбросы (IQR-метод)
- Тренд (1-я половина → 2-я)
- Лидеры с процентными долями
- Предупреждение о концентрации (топ-3 > 70%)
- Форматирование: markdown (жирные заголовки, списки, абзацы), без эмодзи

### Экспорт

- **Excel (.xlsx)** — через `openpyxl`
- **Word (.docx)** — заголовок, meta, таблица до 200 строк
- **PDF (.pdf)** — кириллица через `DejaVuSans`, Executive Summary + таблица до 25 строк

### UI

- Авторизация паролем (`APP_PASSWORD`)
- Чат-интерфейс с историей сообщений
- Примеры запросов в сайдбаре
- Сохранение запросов в избранное (⭐)
- Кнопка очистки чата
- Схема декомпозиции запроса (Graphviz DOT)
- DAX-запрос в expander
- Кастомная CSS-тема (KPI-карточки, фон, отступы)

### Стабильность

- Исторические сообщения — статичный рендеринг (без виджетов → нет проблем при rerun)
- Последнее сообщение — интерактивный рендеринг с полной панелью управления
- NaN/пустые значения заменяются на «(не указано)»
- Числа форматируются: 2.7 млрд, 5.4 млн, 1.5 тыс
